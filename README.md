# PairBytes Frontend Assignment

This project is a mini e-commerce application built using React as part of the PairBytes frontend internship assignment.

The focus of this assignment is on clean component structure, state management using React hooks, API integration, and a usable responsive UI.

## Features
- Fetch products from an external API
- Display products in a grid layout
- Filter products by category
- Sort products by price
- View product details using routing
- Add products to cart with quantity handling
- Persist cart data using localStorage
- Handle loading and error states
- Basic responsive layout for mobile and desktop

## Tech Stack
- React
- React Hooks (useState, useEffect)
- React Router DOM
- Plain CSS
- Fake Store API
